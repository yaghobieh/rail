# Rail 1.0.1 — Telegram paste

🚂 **@forgedevstack/rail@1.0.1** is live

Patch release for the ForgeStack carousel engine:

• A11y: roving tabindex, focus-on-change, aria-roledescription polish
• Autoplay pauses on `prefers-reduced-motion`
• Lazy slide loading (`Lazy` module + `RailSlide lazy`)
• Progressbar tracks continuous progress (+ vertical)
• FreeMode momentum via requestAnimationFrame
• `createBreakpoints()` helpers
• Fixed missing `styles.css` in the published package
